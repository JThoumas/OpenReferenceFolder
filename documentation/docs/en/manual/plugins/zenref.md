# ZenRef

ZenRef is a reference plugin with free-form canvases and a photo viewer.

## Overview

ZenRef is a built-in plugin. You can turn it off in **Preferences > Plugins**, but you cannot uninstall it.

ZenRef has two modes: **Canvas Mode** and **Photos Mode**. Unlike [PureView](pureview.md), ZenRef is not linked to one ORF window.

ZenRef windows can be placed on any monitor.

## Canvas Mode

A canvas is an unbounded surface where you place references and arrange them freely.

1. Create a canvas from the tab menu.
2. Drag images onto the canvas, from ORF or from your file manager.
3. Move, scale and arrange the images.

A collapsible menu lists the tabs of all open canvases.

### Where canvases are stored

Canvases are stored in a `ZenRef` folder in the navigation tree of your file browser.

- Each folder is one canvas.
- A folder inside a canvas folder becomes its own canvas. Your folder hierarchy is kept.

## Photos Mode

Photos Mode is a viewer for the image files in a folder.

- It shows image files only.
- Double-click an image for full screen.
- Use the arrow keys or the on-screen buttons to go to the next or previous image.
