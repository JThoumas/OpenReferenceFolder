# Compact Mode

Compact mode lets the side and outer panels overlay the PureView, so the image stays in view.

## Overview

Compact mode is on by default.

- Side and outer panels overlay the inner panels, such as PureView. They are drawn at reduced opacity.
- A panel becomes solid when you hover over it.
- Floating panels follow the same rules.
- When the pointer leaves the ORF window, only PureView and the plugins that opted in stay visible.

Panels do not let clicks through. Clicking a panel clicks the panel, not the image behind it.

Compact mode works by hover only. It has no pin button and no keyboard shortcut.

## Turn it off

1. Open **Preferences > Compact Mode**.
2. Turn off the ORF window setting at the top of the tab.

Panels are then solid and no longer overlay the inner panels.

## Compact mode for a plugin

Each valid plugin window or panel has its own Compact mode setting.

1. Open **Preferences > Compact Mode**.
2. Find the plugin in the list under the ORF settings.
3. Turn its setting on or off.

A plugin that has it turned on stays visible when the pointer leaves the ORF window. A plugin may offer more than on or off, for example its own opacity.
