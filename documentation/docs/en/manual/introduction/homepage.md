# Homepage

The homepage is where you browse your folders and look at references.

## Overview

The homepage has two main parts:

- **The file browser**, on the right side. It starts with a **navigation tree** that lists the folders and virtual folders you added. See [File Browser](file-browser.md).
- **The PureView tab**, in the center. It covers most of the window and is not linked to a file browser. It works like a plain image viewer. See [PureView](../plugins/pureview.md).

An image dropped on the PureView tab is not saved by default. ORF keeps it in the cache only. You can change this in **Preferences > General**. See [Drag and Drop](drag-and-drop.md).

## Tabs

The tabs at the top of the window are workspace-style tabs. Each tab holds one file browser and the PureView that is linked to it. To look at two folders side by side, add another pair tab. See [PureView](../plugins/pureview.md#more-than-one-pureview) and [Workspaces](workspaces.md).

## Add folders and files

1. Click the **+** button in the navigation tree.
2. Select one or more folders or files in the system dialog.
3. Click **Open**. The items appear as top-level entries of the navigation tree.

Added folders and virtual folders are the top-level entries of the tree. You can also drag folders and files from your system file manager onto the tree. See [Drag and Drop](drag-and-drop.md).

## Remove items

1. Select one or more items in the navigation tree.
2. Right-click and choose **Remove from ORF**.

Removing an item deletes its entry from the index. It does not delete the file or folder on your drive. To delete the file itself, see [File Operations](file-operations.md).

!!! note
    **Remove from ORF** and **Delete** are different commands. Check the command name before you confirm.
