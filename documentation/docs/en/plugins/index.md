# Plugins

Plugins are optional components that add features to ORF. This page lists the first-party plugins. PureView, ZenRef and ORF Folder are built in. You can turn them off in **Preferences > Plugins**, but you cannot uninstall them.

For how plugins work and how to install them, see [Plugins Overview](../manual/plugins/overview.md). To write one, see [Plugin Development](../development/plugin-development.md).

## Format decoders

Decoder plugins let ORF draw previews for more file formats. The built-in formats need no plugin.

| Decoder | Formats | Status |
| --- | --- | --- |
| SVG | `.svg` | First decoder |
| WebP | `.webp` | Planned |
| GIF animation | animated `.gif` | Planned |
| Photoshop | `.psd`, `.psb` | Planned |
| Krita | `.kra` | Planned |
| Clip Studio Paint | `.clip` (preview image) | Planned |
| Illustrator | `.ai` | Later |

See [Supported File Formats](../manual/introduction/supported-files.md) for what each decoder shows.

## Turn plugins on and off, or install one

Built-in plugins need no install step.

1. Open **Preferences > Plugins**.
2. Use the switch of a plugin to turn it on or off.
3. To add a plugin that is not built in, choose **Install** and select a plugin zip file, or drag the zip file onto the page.

The first plugin release is local. An online list of plugins follows later. See [Plugins Overview](../manual/plugins/overview.md) for details.
